# Navi-SEO Intelligence

Plateforme SEO / GEO multi-clients : Next.js (web) + worker pg-boss + agent de logs, PostgreSQL avec Row Level Security, bibliothèque **Navi-SEO Core** réutilisable (`createSeoKit`).

➡️ **Commencez par [`docs/DEVELOPER-GUIDE.md`](docs/DEVELOPER-GUIDE.md)** (état de la livraison, ce qui est vérifié ou non, démarrage, checklist du premier jour).
Décisions d'architecture : [`docs/adr/`](docs/adr).

```bash
pnpm install && pnpm test --project unit && pnpm lint:rls
```
